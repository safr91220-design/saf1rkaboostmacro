# saf1rkaboost

Игровой режим для Windows 10/11 (Python + PySide6). Освобождает ресурсы: сворачивает окна, прячет панель
задач и значки, поднимает приоритет игры, приостанавливает/закрывает только выбранные вами приложения.
**Прирост FPS не гарантируется** — проверяйте замерами.

## Запуск
1. Установите Python 3.10+ (64-бит, галочка «Add to PATH»).
2. В папке проекта:
   ```
   py -m venv venv
   venv\Scripts\activate
   pip install -r requirements.txt
   python main.py
   ```
3. Сборка EXE: `build.bat` → `dist\saf1rkaboost.exe`.

## Использование
- **BOOST** — включает Gaming Mode; **Restore Desktop** — возвращает всё назад. Alt+Tab работает, Explorer не трогается.
- **Процессы** → «Обновить», отметьте приложения → «Закрыть» / «Приостановить». «Запомнить для BOOST» — эти
  приложения будут приостанавливаться при каждом включении режима. Защищены: процессы Windows, антивирусы,
  драйверы, античиты, лаунчеры, чужие аккаунты, сама игра.
- **Настройки** → автоопределение, авто-включение, ручной выбор EXE игры. После закрытия игры всё восстанавливается.
- Лог: вкладка «Лог» и файл `%APPDATA%\saf1rkaboost\saf1rkaboost.log`.

## Как проверить на реальном ПК
1. **Без игры:** BOOST → окна свернулись, панель/значки скрыты, Alt+Tab переключает окна → Restore Desktop → всё вернулось.
2. **Закрытие программы:** включите режим и закройте saf1rkaboost — рабочий стол должен восстановиться сам.
3. **Защита:** на вкладке «Процессы» убедитесь, что svchost, explorer, антивирус, драйверы серые и не выбираются.
4. **Приостановка:** откройте Блокнот/браузер → отметьте → «Приостановить» (окно зависнет) → «Возобновить все».
5. **Игра:** добавьте EXE в Настройках (или запустите игру в полноэкранном режиме) → должен прийти вопрос о включении
   режима; закройте игру → режим выключается сам.
6. **FPS (главное):** CapFrameX / PresentMon / MSI Afterburner. Одна и та же сцена 60–120 с, минимум 3 прогона
   без режима и 3 с ним. Сравнивайте средний FPS и 1% low. Разницы может не быть — это нормально.

## Ограничения
- GPU-нагрузка — только NVIDIA (`nvidia-smi`). Авто-определение — только полноэкранные окна на основном мониторе.
- Закрытый процесс восстановить нельзя; приостановка обратима.
- Окна приложений «от администратора» сворачиваются только если saf1rkaboost запущен от администратора.
- Если программа аварийно завершилась и панель осталась скрытой: `python main.py --restore` (или перезапуск Explorer).
- Не вносит правок в реестр, не отключает Defender, службы, драйверы и античит.

## Меню (по умолчанию)
Компактное окно `saf1rka_boost` с кнопкой **Performance Mode** (включить / повторное нажатие — вернуть всё обратно),
крестик закрывает программу и восстанавливает рабочий стол. Окно поверх остальных, двигается мышкой.
Полный интерфейс (процессы, настройки, лог): `python main.py --full` или ярлык на exe с параметром `--full`.

## Full Desktop Suspend (отключение Explorer)
Кнопка **Full Desktop Suspend** временно завершает `explorer.exe` (панель задач, рабочий стол, Проводник исчезают).
Игра и другие программы продолжают работать. Статус: `Explorer: RUNNING / SUSPENDED`. Реестр, службы и другие
системные процессы не затрагиваются; завершается только explorer.exe текущего пользователя.

Возврат: **RESTORE DESKTOP**, закрытие игры, выход из программы, ошибка программы, а также:
- **Ctrl+Alt+Shift+R** — глобальное аварийное сочетание (работает, пока Explorer отключён);
- отдельный процесс-«сторож»: если программа внезапно завершилась, он сам запустит Explorer;
- вручную: Ctrl+Shift+Esc → «Запустить новую задачу» → `explorer.exe` (или `saf1rkaboost.exe --restore`).

Explorer запускается не более 2 раз подряд, бесконечных циклов нет. Если Windows сама перезапустит Explorer,
программа не будет с ним бороться — статус просто станет RUNNING.

**Alt+Tab:** штатный переключатель живёт внутри Explorer, поэтому при его отключении программа включает свой
Alt+Tab (список окон по центру экрана, Tab — дальше, Shift+Tab — назад, Esc — отмена; переключение при отпускании Alt).
Окна, свёрнутые в трей (например Discord в трее), в списке не видны — откройте их заранее.
Не запускайте программу «от администратора»: тогда Explorer запустится с повышенными правами.

### Тест механизма (сначала сделайте его)
Сохраните работу, откройте командную строку в папке с exe и выполните `saf1rkaboost.exe --test-shell`
(или `python main.py --test-shell`). Explorer отключится на 10 секунд и вернётся сам.
Затем проверьте: отключение → Блокнот продолжает работать → Alt+Tab → RESTORE DESKTOP → панель вернулась;
закрытие программы при отключённом Explorer → панель вернулась; завершение программы через диспетчер задач
при отключённом Explorer → через ~1–2 с сторож вернул панель.

## Optimization Log
Кнопка **Optimization Log** показывает все действия программы (что свёрнуто, приостановлено, поднят приоритет, включён/выключен
Alt+Tab, состояние Explorer) и метрики «до / через 8 секунд» (CPU, RAM, число процессов).
FPS автоматически не измеряется: впишите «FPS до» и «FPS после» из оверлея игры (Steam / MSI Afterburner / NVIDIA) —
программа посчитает прирост в процентах и запишет в лог. Если разница меньше 1%, она так и напишет: «в пределах погрешности».

## Окно программы: FPS BOOST + MACROS
Запуск по умолчанию (`python main.py` / exe) открывает единое окно с боковой панелью **FPS BOOST** и **MACROS**
(внизу — **SETTINGS**). Прежние окна сохранены: `--menu` (компактное меню) и `--full` (старое большое окно).

### FPS BOOST
ENABLE BOOST = Performance Mode + отключение Explorer (с предупреждением), RESTORE DESKTOP возвращает всё.
Статус `DESKTOP ACTIVE / DESKTOP SUSPENDED`, CPU/RAM/GPU, журнал действий, настраиваемая аварийная горячая клавиша.
**AUTO MODE** включает Boost только для игр из вашего списка (ADD EXE) и восстанавливает всё при выходе из игры.
Восстановление при ошибке/внезапном закрытии: сторож-процесс, горячая клавиша, `saf1rkaboost.exe --restore`.

### MACROS
Профили (Default, Fortnite; создание, переименование, копия, удаление, импорт/экспорт JSON) · категории
EDIT / DOUBLE / SINGLE / DROP / SIT / PICKAXE · для каждой: SELECT KEY, EDIT KEY, ACTIVATE KEY, SEQUENCE,
EDIT DELAY, KEY DELAY (ползунок + поле, 0–1000 мс), SAVE, RESET у каждой настройки, ENABLE.
- Клик по полю клавиши → «PRESS A KEY…» → нажмите клавишу или кнопку мыши (средняя, X1, X2; левая/правая — для SELECT/EDIT). Esc — отмена.
- **ACTIVATE KEY** — клавиша, которую нажимаете вы; программа тогда отправляет SEQUENCE.
  Шаги: `SELECT`, `EDIT`, `KEY:F5` (нажатие), `+EDIT` / `-EDIT` (зажать/отпустить), `W:EDIT`, `W:KEY`, `W:25` (пауза, мс).
  Стартовые последовательности — шаблоны, подберите их под свои бинды. DOUBLE по умолчанию — два нажатия EDIT с паузой KEY DELAY.
- Конфликты клавиш подсвечиваются; макрос с занятой ACTIVATE KEY включить нельзя.
- Защиты: повтор удержания клавиши игнорируется, повторный запуск во время работы/в течение 120 мс игнорируется,
  потолок 5 с на макрос, наши же нажатия не запускают макросы, при остановке все зажатые клавиши отпускаются.
- Остановка: горячая клавиша STOP ALL MACROS (по умолчанию Ctrl+Shift+F12), выключатель MACRO ENGINE (Ctrl+Shift+F11).
- «ONLY WHEN GAME IS FOCUSED» + GAME EXE: макросы работают только когда окно этой игры активно (для Fortnite указан по умолчанию).
- Настройки хранятся в `macros.json` (папку можно сменить в SETTINGS).

**Важно:** макросы отправляют нажатия через SendInput. Игры с античитом (Fortnite — Easy Anti-Cheat) могут считать это
нарушением правил и блокировать аккаунт. Программа не внедряется в процессы игр и не обходит защиту — риск ваш.
Если игра запущена «от администратора», запустите программу тоже от администратора (иначе ввод не пройдёт);
но для FPS BOOST администратор не нужен (Explorer запустится с повышенными правами).

### Сборка EXE
`build.bat` или `pyinstaller --noconfirm --onefile --windowed --name saf1rkaboost main.py`. Резервная копия прежнего кода — в `backup_before_macros/`.
